Printer

Mobile Zebra printers often ship in CPCL/line-print mode and would print the code as text. This sends a one-line setting so the printer accepts ZPL.
Not connected. Turn on the printer's Bluetooth, then tap Connect.
 for testing in a ZPL viewer
Uses the phone's print screen. On Android, install your printer's print-service plugin (Zebra Printing / Brother / Mopria). On iPhone, use an AirPrint printer. Set the paper size to the label size in the print screen.

Print settings

⚠ This size is wider than the Zebra ZR328 (72 mm). Choose a 72 mm size, or the label will be cut off.
